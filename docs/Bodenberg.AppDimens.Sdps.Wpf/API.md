## Namespace `AppDimens.Sdps.Wpf`

### `AppDimensWpf` (static class)

Entry point for WPF apps. Call `Initialize` once (e.g. in the `MainWindow` constructor, before `InitializeComponent()`) and every `{sdps:Sdp 16}` value follows the window size from then on.

**Properties**

| Signature | Description |
|-----------|-------------|
| `static Window TrackedWindow { get; }` | The window whose size drives the values (null in screen fallback mode). |
| `static bool IsInitialized { get; }` | True after `Initialize` (or the automatic screen fallback). |

**Events**

| Signature | Description |
|-----------|-------------|
| `static event EventHandler Changed` | Raised on the UI thread after the window was resized, moved to another monitor (DPI change) or re-attached. Use it to recompute values set from code-behind. |

**Methods**

| Signature | Description |
|-----------|-------------|
| `static void Detach()` | Stops tracking the window (values keep their last size). |
| `static void EnsureInitialized()` | Starts AppDimens using the primary screen work area (no window tracking). Called automatically by the markup extensions when nothing was initialized. |
| `static void Initialize(Window window, AppDimensOptions options = null, string generatedResourcesPath = null)` | Starts AppDimens for a WPF window. Safe to call again with another window (e.g. when the main window changes). |
| `static void Refresh()` | Forces a re-read of the window size and DPI. |

### `DimenExtensionBase` (abstract class)

Base class of every `{sdps:Xxx 16}` markup extension. By default the value is live: it is bound to the window size and recalculated automatically on resize. Works for `double` properties (Width, Height, FontSize…) and converts to `Thickness`, `CornerRadius` and `GridLength` automatically.

Inherits / implements: `MarkupExtension`

**Properties**

| Signature | Description |
|-----------|-------------|
| `DimenTarget As { get; set; }` | Forces the output type; `Auto` detects it from the property. |
| `bool Live { get; set; }` | When true (default) the value updates on window resize. |
| `int Value { get; set; }` | Design value in dp (the number you would use on a 300dp-wide reference screen). |
