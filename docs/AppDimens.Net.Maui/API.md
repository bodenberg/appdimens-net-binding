### `AppDimensMaui` (static class)

Bootstrap for .NET MAUI apps: wires the ambient context, initializes the cache and installs the event-driven resize watcher. Call once in `MauiProgram` after building the `Application`, or attach per-window with `AttachWindow`.

### `WindowDimensScope` (sealed class)

Live window scope backed by a MAUI `Window`: recomputes the immutable `ScreenConfiguration` on every SizeChanged / DisplayInfoChanged and notifies registered listeners synchronously — the .NET counterpart of the KMP event-driven config watcher.
