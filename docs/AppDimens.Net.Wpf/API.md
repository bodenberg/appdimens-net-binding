### `AppDimensWpf` (static class)

Entry point for WPF apps. Call `Initialize` once (e.g. in the `MainWindow` constructor, before `InitializeComponent()`): from then on `16.Sdp()` and `{ad:Sdp 16}` follow the window size and DPI.

### `DimenExtensionBase` (abstract class)

Base class of every `{ad:Xxx 16}` markup extension. By default the value is live: it is bound to the window size and recalculated automatically on resize. Works for `double` properties (Width, Height, FontSize…) and converts to `Thickness`, `CornerRadius` and `GridLength` automatically.

Inherits / implements: `MarkupExtension`

**Properties**

| Signature | Description |
|-----------|-------------|
| `DimenTarget As { get; set; }` | Forces the output type; `Auto` detects it from the property. |
| `bool Live { get; set; }` | When true (default) the value updates on window resize. |
| `int Value { get; set; }` | Design value in dp (the number you would use on a 300dp-wide reference screen). |
