## Namespace `AppDimens.Sdps.WinForms`

### `AppDimensWinForms` (static class)

Entry point for Windows Forms apps. Call `Initialize` in your main form constructor, then size controls inside `Apply` so they are recalculated every time the form is resized or moved to another monitor.

**Properties**

| Signature | Description |
|-----------|-------------|
| `static Form TrackedForm { get; }` | The form whose client area drives the values. |
| `static bool IsInitialized { get; }` |  |
| `static double Density { get; }` | Pixels per dp of the tracked form (1.0 at 96 DPI, 1.5 at 144 DPI…). |

**Events**

| Signature | Description |
|-----------|-------------|
| `static event EventHandler Changed` | Raised (UI thread) after the tracked form was resized or changed DPI. |

**Methods**

| Signature | Description |
|-----------|-------------|
| `static IDisposable Apply(Control owner, Action layout)` | Runs `layout` now and again after every resize / DPI change, until `owner` is disposed. Put all your AppDimens sizing inside it. |
| `static void Detach()` | Stops tracking the form. |
| `static void Initialize(Form form, AppDimensOptions options = null, string generatedResourcesPath = null)` | Starts AppDimens for a form. Calling again with another form switches tracking. |
