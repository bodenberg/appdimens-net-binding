### `AppDimensWinUI` (static class)

Entry point for WinUI 3 (Windows App SDK) apps. Call `Initialize` right after creating the main window in `App.OnLaunched`; `16.Sdp()` and `{ad:Sdp Value=16}` then follow the window size.

### `DimenExtensionBase` (abstract class)

Base class of every `{ad:Xxx Value=16}` markup extension. The value is converted to the property type (double, Thickness, CornerRadius, GridLength) and, when `Live` is true (default), re-applied automatically after every window resize.

Inherits / implements: `MarkupExtension`

**Properties**

| Signature | Description |
|-----------|-------------|
| `DimenTarget As { get; set; }` | Forces the output type; `Auto` detects it from the property. |
| `bool Live { get; set; }` | When true (default) the value is updated on window resize. |
| `int Value { get; set; }` | Design value in dp (the number you would use on a 300dp-wide reference screen). |
