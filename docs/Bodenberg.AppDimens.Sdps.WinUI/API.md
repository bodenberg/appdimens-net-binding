## Namespace `AppDimens.Sdps.WinUI`

### `AppDimensWinUI` (static class)

Entry point for WinUI 3 (Windows App SDK) apps. Call `Initialize` right after creating your main window (in `App.OnLaunched`) and `{sdps:Sdp Value=16}` values follow the window size.

**Properties**

| Signature | Description |
|-----------|-------------|
| `static Window TrackedWindow { get; }` | The window whose size drives the values. |
| `static bool IsInitialized { get; }` |  |

**Events**

| Signature | Description |
|-----------|-------------|
| `static event EventHandler Changed` | Raised after the window was resized or its scale (DPI) changed. |

**Methods**

| Signature | Description |
|-----------|-------------|
| `static void Detach()` | Stops tracking the window (values keep their last size). |
| `static void Initialize(Window window, AppDimensOptions options = null, string generatedResourcesPath = null)` | Starts AppDimens for a WinUI 3 window. Calling again with another window switches tracking. |
| `static void Refresh()` | Forces a re-read of the window size and scale. |

### `DimenExtensionBase` (abstract class)

Base class of every `{sdps:Xxx Value=16}` markup extension. The value is converted to the property type (double, Thickness, CornerRadius, GridLength) and, when `Live` is true (default), re-applied automatically after every window resize.

Inherits / implements: `MarkupExtension`

**Properties**

| Signature | Description |
|-----------|-------------|
| `DimenTarget As { get; set; }` | Forces the output type; `Auto` detects it from the property. |
| `bool Live { get; set; }` | When true (default) the value is updated on window resize. |
| `int Value { get; set; }` | Design value in dp (the number you would use on a 300dp-wide reference screen). |
