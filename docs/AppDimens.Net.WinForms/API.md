### `DimenPx` (static class)

Converts AppDimens dp values to Windows Forms units.

**Methods**

| Signature | Description |
|-----------|-------------|
| `static Padding Padding(double dp)` | Same dp value on all four sides, in pixels. |
| `static Size Size(double widthDp, double heightDp)` | Width × height in pixels. |
| `static float ToPt(double dp)` | dp → typographic points (1 dp = 1/96 inch = 0.75 pt). Use for `Font` sizes. |
| `static int Of(DimenFunction function, int value)` | Evaluates any `DimenFunction` straight to pixels: `DimenPx.Of(DimenFunction.FSdp, 24)`. |
| `static int ToPx(double dp)` | dp → physical pixels of the tracked form (rounded). |
